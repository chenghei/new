# 接口清单

## 一、通用约定

- **Base URL**：`http://localhost:5000/api`
- **请求体**：`application/json`（图片上传为 `multipart/form-data`）
- **鉴权方式**：请求头 `Authorization: Bearer <token>`（登录接口返回的 JWT）
- **统一响应格式**：

```json
{
  "success": true,
  "message": "操作成功",
  "data": {},
  "timestamp": "2026-01-01T00:00:00.000Z"
}
```
失败时 `success: false`，并返回 `message`；HTTP 状态码同时表达语义（400 参数/业务错误、401 未登录、403 权限不足、404 不存在、500 服务器错误、504 AI 超时）。

- **权限标记说明**

| 标记 | 含义 |
|---|---|
| 公开 | 无需登录 |
| 可选登录 | 有 token 则解析用户（用于记录浏览历史等），无 token 也可访问 |
| 登录 | 需有效 JWT |
| 管理员 | 需 `role = admin` |
| 登录（商家） | 需商家账号（入驻审核通过后自动升级角色） |

- **静态资源**：上传的图片保存在 `backend/uploads`，通过 `GET /uploads/<文件名>` 访问。

## 二、认证 `/api/auth`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/auth/register` | 公开 | 注册（username、email、password、nickname?） |

## 三、用户 `/api/users`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/users` | 管理员 | 用户列表，参数：`page`、`limit`、`search`、`role`、`status` |
| GET | `/users/:id` | 登录 | 用户详情 |
| PUT | `/users/:id` | 登录 | 更新资料（`nickname`、`avatar`、`phone`；管理员可改 `role`） |
| PUT | `/users/:id/password` | 登录 | 修改密码（`oldPassword`、`newPassword`） |
| PUT | `/users/:id/identity` | 登录 | 实名认证（`real_name`、`id_card`） |
| DELETE | `/users/:id` | 管理员 | 删除用户（不能删除自己） |
| PATCH | `/users/:id/status` | 管理员 | 启用/禁用账号（切换 active/inactive） |

## 五、商品 `/api/products`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/products` | 可选登录 | 商品列表。参数：`page`、`limit`、`category_id`、`keyword`/`name`、`price_min`、`price_max`、`sortBy`(id/name/price/sales/created_at/updated_at)、`order`、`merchant_id`、`audit_status`、`scope`(all/mine)。非管理员仅能看到**上架且审核通过**的商品 |
| GET | `/products/:id` | 可选登录 | 商品详情；登录用户访问会记录浏览历史（用于 AI 推荐） |
| POST | `/products` | 登录 | 新增商品（商家/用户创建后 `audit_status = pending`，管理员直接生效）；商家若已在店铺中设置经营类目，商品分类**强制取店铺经营类目** |
| PUT | `/products/:id` | 登录 | 修改商品；修改内容会重新进入待审核，**仅切换上下架不触发重审** |
| DELETE | `/products/:id` | 登录 | 删除商品（仅本人或管理员） |
| POST | `/products/upload` | 登录 | 图片上传（`file` 字段，≤5MB，jpg/png/gif），返回文件名 |

## 七、订单 `/api/orders`（均需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/orders` | 订单列表。参数：`page`、`limit`、`status`。管理员看全部；商家看自己商品相关订单；用户看自己的 |
| GET | `/orders/statistics` | 各状态订单数量与总额统计 |
| GET | `/orders/:id` | 订单详情（管理员/所属人可见） |
| POST | `/orders` | 单商品下单（`product_id`、`quantity`、`receiver_name`、`receiver_phone`、`receiver_address`、`remark`） |
| POST | `/orders/batch` | 购物车批量结算（`items[]`、`cart_ids[]`、收货人信息），事务 + 原子扣减 |
| POST | `/orders/:id/pay` | 模拟支付（pending → paid） |
| POST | `/orders/:id/confirm` | 确认收货（shipped → completed） |
| POST | `/orders/:id/cancel` | 取消订单（pending → cancelled，库存回补） |
| PUT | `/orders/:id` | 修改订单状态（管理员 / 商品所属商家，如发货 `{"status":"shipped"}`） |

**订单状态机**：`pending 待支付 → paid 已支付 → shipped 已发货 → completed 已完成`，`pending → cancelled 已取消`。

## 十、售后 `/api/after-sales`（均需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/after-sales/mine` | 我的售后申请列表 |
| GET | `/after-sales/:id` | 售后详情（本人或管理员） |
| POST | `/after-sales` | 申请售后（`order_id`、`type`: refund/return、`reason`）；事务 + 行锁防重复提交 |
| PUT | `/after-sales/:id/cancel` | 撤销申请（仅待处理） |
| PUT | `/after-sales/:id/process` | 处理售后（管理员/商品所属商家）：`approved`/`rejected`/`completed` + `handle_remark` |

**售后状态**：`pending 待处理 → approved 已同意 / rejected 已拒绝 / completed 已完成`。
可申请售后的订单状态：`paid`、`shipped`、`completed`；未发货订单只能「仅退款」。

## 十二、AI `/api/ai`（均需登录）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/ai/recommend` | AI 个性化推荐（返回 `recommendations[{product, reason}]` 与 `source`：ai/hot/fallback/empty） |
| POST | `/ai/chat` | AI 导购对话（`messages[{role, content}]`） |

以上调用均会写入 AI 调用记录；模型不可用时自动降级（推荐→热销、评价分析→规则化摘要）。

## 十四、管理端 `/api/admin`（全部需管理员，路由层统一鉴权）

### 店铺与商家
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/shops?status=` | 店铺列表（pending/approved/rejected），含申请人与资质信息 |
| PUT | `/admin/shops/:id/audit` | 审核店铺：`{status: approved/rejected, reject_reason}`；通过后账号角色升级为 merchant |
| GET | `/admin/merchants` | 商家列表（含店铺），参数：`page`、`limit`、`keyword`、`status`、`shop_status` |
| PATCH | `/admin/merchants/:id/status` | 启用/禁用商家账号：`{status: active/inactive}` |

### 商品审核
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/products?audit_status=pending` | 商品审核列表 |
| PUT | `/admin/products/:id/audit` | 审核商品：`{audit_status: approved/rejected, audit_remark}` |

### 售后监管
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/after-sales` | 平台售后列表，参数：`page`、`limit`、`status`、`type`、`abnormal=1`（异常：已拒绝或超 3 天未处理）、`keyword`（订单号） |

### 平台统计
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/stats` | 平台概览（用户/商家/商品/订单/销售额/评价/待办等 14 项） |
| GET | `/admin/sales-trend?days=7` | 平台销售趋势 |
| GET | `/admin/user-growth?days=7` | 用户增长趋势 |
| GET | `/admin/order-status` | 订单状态分布 |
| GET | `/admin/category-distribution` | 商品分类分布 TOP8 |
| GET | `/admin/recent-orders?limit=8` | 最近订单 |

### AI 管理
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/ai/logs` | AI 调用记录，参数：`page`、`limit`、`scene`、`status`、`keyword`；返回调用概览统计 |
| GET | `/admin/ai/logs/:id` | 调用记录详情 |
| DELETE | `/admin/ai/logs/:id` | 删除调用记录 |
| GET | `/admin/ai/contents` | AI 生成内容（文案生成/评价分析），参数：`page`、`limit`、`scene`、`keyword` |
| GET | `/admin/ai/config` | AI 服务配置（密钥脱敏，返回 `api_key_masked`、`key_source`） |
| PUT | `/admin/ai/config` | 保存 AI 配置（`api_key`、`base_url`、`model`、`temperature`、`max_tokens`、`enabled`）；密钥留空表示不修改 |
| POST | `/admin/ai/config/test` | 测试 AI 连通性（可传未保存的配置试连） |
